# 《坚果矿洞大冒险：七日与千年的心愿》STC-B 战斗联动流程

这份说明对应 `battle_demo.py` 的实现，也是一份可以直接交给开发助手的需求描述模板。

## 运行链路

```text
STC-B 固件
  ├─ 每秒发送 0x40 hi lo（光照 ADC）
  ├─ 每秒发送 0x41 hi lo（温度 ADC，当前战斗页只记录）
  ├─ 震动时发送 0x09
  └─ 串口 9600 baud
       ↓
STCSerialBridge
  ├─ 解析三字节传感器帧，不修改 ADC 原值
  ├─ 将 0x01..0x06 转成方向、确认和重置事件
  └─ 将 0x09 转成与键盘 Z 相同的内部事件
       ↓
BattleEncounterDemo
  ├─ 持续刷新右下角技能说明
  ├─ 超音蝠/可可多拉战：日光束 70..120，光合作用 30%..50%
  ├─ 勾魂眼战：日光束 40..80，光合作用 20%..40%
  └─ 当前选中重磅冲撞时，串口 0x09 与键盘 Z 共用确认路径
```

## 光照映射

```text
value = minimum + round(clamp(light, 0, 105) × (maximum - minimum) / 105)
```

超音蝠和可可多拉战使用日光束 `70..120`、光合作用 `30%..50%`；勾魂眼战使用日光束 `40..80`、光合作用 `20%..40%`。每次攻击会在对应文本指定的基础伤害区间内均匀抽取一个整数；日光束再按照“实时威力 / 初始威力”缩放这次抽取结果。

## 启动

```powershell
python battle_demo.py
python battle_demo.py --port COM3
scripts\run_battles.bat COM3
```

剧情主程序的树林龟教学战也使用同一串口协议：

```powershell
python adventure.py COM3
```

树林龟教学战和独立战斗演示统一使用 `0..105` 的光照标定。串口层只拆包，不转换 ADC；进入技能确认时才读取最新值，因此开发板每秒发送的新光照会立即反映在技能栏和本次效果中。教学战与超音蝠、可可多拉战均显示日光束威力 `70..120`、光合作用回复 `30%..50%`。

战斗中选择日光束或光合作用时，右侧数值会跟随最近收到的光照 ADC 更新。选择重磅冲撞后，晃动开发板发送 `0x09`，效果等同于按 `Z`。

## 推荐提示词写法

```text
请在现有 Python/Pygame 战斗项目中接入 STC-B 串口，不改变现有战斗界面和资源。
固件串口参数为 9600 baud：0x40 后跟两个字节是光照 ADC，0x41 后跟两个字节是温度 ADC，0x09 是一次震动事件。
串口层只负责按协议拆包并转发原始值，不做温度换算或伤害计算。
在战斗界面中持续显示原始光照值，并按以下明确规则更新主角技能说明：
光照 0 到 105 采用线性插值。超音蝠和可可多拉战中，日光束为 70 到 120、光合作用为 30% 到 50%；勾魂眼战中分别为 40 到 80、20% 到 40%。
每次造成伤害时，在对应 battle_with_*.txt 指定的整数上下限内均匀随机取值；日光束还要乘以实时威力与该场初始威力之比。
震动事件 0x09 必须调用与键盘 Z 完全相同的重磅冲撞处理函数。
请先阅读现有入口、串口协议和测试，再修改代码；补充单元测试覆盖 0、90、105 和超范围值，并说明启动命令。
```
